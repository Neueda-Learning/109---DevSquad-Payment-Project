# 109---DevSquad-Payment-Project
# 💳 Smart Payment Management System

A full-stack payment management application built with **React** for the frontend and **Spring Boot** for the backend. The platform simplifies personal and business payments by providing intelligent payment management, scheduling, anomaly detection, and multi-beneficiary transactions.

---

# 🚀 Tech Stack

### Frontend

* React
* JavaScript
* HTML5
* CSS3

### Backend

* Spring Boot
* Java
* REST APIs

---

# ✨ Features

## 💰 Create New Payments

* Create and manage payment requests with a simple and intuitive interface.
* Store payment details securely for future reference.

---

## 🌍 Multi-Currency Support

* Perform transactions in multiple currencies.
* Easily switch between supported currencies while creating payments.

---

## 💳 Multiple Payment Modes

Supports various payment methods, including:

* Credit Card
* Debit Card
* Bank Transfer
* UPI
* Digital Wallets

---

## ⚠️ Payment Anomaly Detection

* Automatically detects unusually large payment amounts.
* Displays a warning popup whenever the payment exceeds a predefined threshold.
* Helps prevent accidental or suspicious transactions.

---

## 🏷️ Payment Filtering Using Tags

* Organize payments with custom tags.
* Quickly filter and search transactions based on categories such as:

  * Personal
  * Business
  * Bills
  * Shopping
  * Travel
  * Others

---

## 📄 Receipt Download

* Generate and download payment receipts.
* Useful for record keeping and reimbursement purposes.

---

## 👥 Multi-Person Payment (Key Feature)

One of the standout features of the application.

Instead of making multiple individual transactions, users can:

* Add multiple recipients (3–4 or more).
* Specify different payment amounts for each recipient.
* Review the payment summary.
* Complete all payments in a single transaction.

This feature significantly reduces effort when splitting bills, paying teams, reimbursing expenses, or making bulk transfers.

---

## 📅 Scheduled Payments

* Schedule payments for a future date and time.
* Automate recurring or planned transactions.
* Never miss important payments.

# 📖 Project Overview

This project aims to modernize digital payment management by combining flexibility, security, and convenience. It enables users to perform individual or bulk payments, manage transactions efficiently using tags, detect anomalous payments, schedule future transactions, and download receipts—all through a clean React interface backed by a robust Spring Boot backend.
